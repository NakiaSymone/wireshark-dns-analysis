# wireshark-dns-analysis
Wireshark project analyzing DNS traffic and domain-to-IP resolution

## Objective
Capture and analyze DNS traffic to understand how domain names resolve into IP addresses.

## Tools Used
- Wireshark

## Steps
1. Installed Wireshark
2. Captured live network traffic
3. Visited websites to generate traffic
4. Filtered DNS traffic using Wireshark
5. Analyzed DNS queries and responses

## Key Findings
- Websites generate DNS requests before loading
- DNS returns IP addresses for each domain
- Devices use IP addresses to communicate

## What I Leared
- How DNS resolution works
- How to filter netwrok traffic in Wireshark
- How devices communicate over a network
